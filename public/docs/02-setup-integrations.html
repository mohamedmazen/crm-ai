    الإعداد والتكاملات (BYOK)

    هذا أهم دليل في المنصة. AYDRA توفّر التخزين والتشغيل، لكن كل قناة تحتاج مفاتيحك أنت: واتساب، إنستجرام، SMS، البريد، الذكاء الاصطناعي، والمتجر. إن لم تُدخل المفاتيح، لن تعمل القناة — وهذا سلوك مقصود وليس عطلًا.

    ⚠️

    قبل أن تبدأ: جهّز بيانات كل تكامل في مكان واحد. معظم تذاكر الدعم سببها مفتاح ناقص أو منتهي أو مفتاح تجريبي بدل الإنتاجي.

    1. واتساب (WhatsApp Cloud API)

    الربط من صندوق الوارد ← إعداد القنوات. الطريقة المفضّلة هي Embedded Signup: تضغط زر الربط، تسجّل الدخول بحساب Meta، وتختار رقمك — فيُربط تلقائيًا.

    الربط التلقائي (Embedded Signup)

    1. اضغط ربط واتساب واختر «المتابعة عبر Meta».
    2. سجّل الدخول بحساب Facebook الذي يملك Business Account.
    3. اختر أو أنشئ WhatsApp Business Account.
    4. اختر رقم الهاتف. الرقم لا يجب أن يكون مسجّلًا على تطبيق WhatsApp العادي — إن كان كذلك، احذفه من التطبيق أولًا.
    5. أكمل الصلاحيات ثم انتظر رسالة النجاح.

    الربط اليدوي (Manual)

    1. من Meta Business Suite أنشئ تطبيقًا واحصل على: WABA ID، Phone Number ID، وPermanent Token (من System User).
    2. من صفحة الإعداد اضغط «ربط يدوي» وأدخل القيم الثلاث.
    3. أضف عنوان الـWebhook الظاهر في الصفحة إلى إعدادات التطبيق في Meta، ثم تحقّق منه.
    4. بعد الربط اضغط مزامنة أرقام الهاتف ثم مزامنة القوالب.
    🚫

    التوكن المؤقت ينتهي بعد 24 ساعة. استخدم Permanent Token من System User. راقب «صحة الاتصال» في صفحة الإعداد: لو ظهر أن التوكن منتهٍ، القناة ستتوقف عن الإرسال.

    القوالب

    أي رسالة تبدأ بها محادثة على واتساب يجب أن تكون Template معتمد. أنشئها من التسويق ← قوالب واتساب، وانتظر موافقة Meta (قد تأخذ دقائق إلى 24 ساعة). القوالب المرفوضة تُظهر سبب الرفض — عدّلها وأعد الإرسال.

    2. إنستجرام وماسنجر

    1. من صفحة إعداد القنوات اختر Instagram أو Messenger.
    2. سجّل الدخول بحساب Facebook الذي يدير الصفحة.
    3. اختر الصفحة (Messenger) أو الحساب التجاري (Instagram).
    4. وافق على صلاحيات إدارة الرسائل والنشر.
    ⚠️

    إن ظهرت رسالة عن Content-Security-Policy أو عدم تحميل Facebook SDK، فالمشكلة في إعدادات السيرفر/البروكسي وليست في حسابك. راجع مسؤول المنصة.

    3. الرسائل النصية (SMS)

    من التسويق ← بوابات SMS. المزوّدون المدعومون:

    المنطقةالمزوّدون
    عالميTwilio · Vonage (Nexmo) · Telnyx · ClickSend · Amazon SNS
    مصرSMS Misr · Cequens
    الخليجUnifonic · Taqnyat · Msegat · Infobip
    1. اختر المزوّد.
    2. أدخل المفاتيح المطلوبة (API Key / SID / Token حسب المزوّد).
    3. أدخل Sender ID المعتمد من المزوّد.
    4. احفظ ثم اضغط اختبار الاتصال إن كان متاحًا.
    5. أرسل رسالة تجريبية لرقمك قبل أي حملة.
    💡

    لو فشل الإرسال رغم صحة المفاتيح، فراجع: رصيد الحساب، اعتماد الـSender ID، وصيغة الرقم الدولي (مثال: 2010… بدون + أو أصفار بادئة).

    4. البريد الإلكتروني (SMTP)

    من التسويق ← سيرفر البريد. هذا السيرفر يُستخدم في حملات البريد والتسلسلات البريدية وإشعارات النظام إن ربطته.

    1. أدخل Host وPort (587 مع TLS أو 465 مع SSL عادة).
    2. أدخل اسم المستخدم وكلمة المرور.
    3. حدّد From Email وFrom Name.
    4. احفظ ثم أرسل رسالة تجريبية.
    ⚠️

    استخدم بريدًا على دومينك، واضبط SPF وDKIM عند مزوّد الدومين. بدون ذلك ستذهب رسائلك إلى Spam حتى لو كان الـSMTP سليمًا.

    5. الذكاء الاصطناعي (BYOK)

    الربط من الإعدادات ← مزوّدو الذكاء الاصطناعي. المزوّدون المدعومون: OpenRouter · OpenAI · Anthropic · Gemini.

    1. افتح المزوّد واضغط «إضافة مفتاح».
    2. الصق الـAPI Key (يُخزّن مشفّرًا ولا يُعرض بعد الحفظ).
    3. اختر موديل الشات الافتراضي.
    4. فعّل المزوّد.
    5. إن كنت ستستخدم قواعد المعرفة، فعّل مزوّدًا يدعم Embeddings (OpenAI أو Gemini).
    🚫

    قواعد المعرفة لا تعمل بدون مزوّد Embeddings مفعّل. لو ظهر تحذير أعلى الصفحة، فالمقصود ذلك.

    6. المتاجر الإلكترونية

    Shopify

    1. من المبيعات ← المتاجر ← إضافة متجر اختر Shopify.
    2. أدخل دومين المتجر بصيغة your-store.myshopify.com (ليس الدومين المخصص).
    3. أنشئ Admin API Access Token بصلاحيات قراءة الطلبات والمنتجات، وأدخله.
    4. انسخ Webhook Secret وأضفه في Shopify عند إعداد الـWebhooks.

    WooCommerce

    1. أدخل رابط المتجر الكامل (https://shop.example.com).
    2. من WooCommerce ← Settings ← Advanced ← REST API أنشئ مفتاحًا بصلاحيات Read/Write.
    3. أدخل Consumer Key وConsumer Secret.
    4. احفظ ثم اضغط «مزامنة» لتأكيد الاتصال.

    7. الدومين والـSubdomain

    • Subdomain: مثل acme يصبح acme.<base-domain>. يضبطه مدير المنصة من شاشة العملاء.
    • Custom Domain: مثل crm.company.com. يحتاج ضبط DNS (CNAME أو A) إلى سيرفر المنصة، ثم شهادة SSL.
    • بعد تغيير الدومين، انتظر انتشار الـDNS (قد يصل إلى 24 ساعة).

    8. الـWebhooks الصادرة

    من الإعدادات ← Webhooks. تُستخدم لإبلاغ أنظمتك الخارجية بالأحداث (مثل إنشاء ليد أو استلام رسالة).

    1. أضف Endpoint (رابط HTTPS يستقبل POST).
    2. اختر الأحداث المطلوبة.
    3. احتفظ بالـSecret للتحقق من توقيع الطلب.
    4. استخدم «إرسال تجريبي» ثم راجع «سجل التسليمات» عند أي فشل.
