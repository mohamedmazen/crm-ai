    Guide 08 · Manager / marketing

    Automation & AI

    Automation runs a chain of actions when a certain event happens. AI adds smart replies and knowledge bases. Together they save hours of work every day — but start simple.

    Part One: Automation

    What is automation?

    A visual scenario: a trigger → sequential steps (nodes). For example: “when a contact is created → wait an hour → send a welcome WhatsApp message”.

    Creating an automation

    1. Open Automation → Automation and click New Automation.
    2. Choose the trigger from the list.
    3. Open the builder.
    4. Drag the steps from the node panel and connect them to one another.
    5. Configure each step (text, template, delay, conditions...).
    6. Use Test to simulate a run without actually sending.
    7. Enable the automation.

    Conditions

    The condition step checks a field such as: the contact's name/email/phone/tag, the message text, or a key in the context. The operators are: equals, does not equal, contains, does not contain, exists, does not exist.

    Testing and runs

    • Test: simulates all the steps and shows the result without sending or writing any data.
    • Runs log: shows every run and its status. A failed run shows the step and the reason.
    • AI generator: write a description in plain language (“a welcome message, then wait a day, then ask about the service”) to generate the scenario.
    • Webhook Trigger Token: each automation has a token you can call from an external system to start a run.

    Automation fields reference

    An automation is stored as a trigger plus a graph of nodes and edges. The builder edits the graph; the list shows the summary fields.

    FieldWhat it means
    NameWhat the automation does, written for the team.
    StatusActive runs on every matching event; paused stores the workflow but does nothing.
    TriggerThe event that starts the run, such as contact.created or lead.won.
    Trigger configExtra filters on the trigger, for example a pipeline or a tag.
    NodesThe steps: send a message, wait, create a task, update a field, call a webhook…
    EdgesHow steps connect, including conditions and branches.
    Run countHow many times the automation has executed.
    Run logPer-record history with the step reached and any error.

    Part Two: Artificial Intelligence

    1. AI Providers

    From Settings → AI Providers. Supported: OpenRouter · OpenAI · Anthropic · Gemini.

    1. Open the provider and add the API key (stored encrypted).
    2. Choose the default chat model.
    3. Enable the provider.
    4. If you are going to use knowledge bases, enable OpenAI or Gemini (they support embeddings).
    🚫

    Without a valid key, every AI feature stops: the chatbot, the AI reply, scenario generation, call summaries, the lead advisor, and AI posts.

    2. Knowledge Bases

    From Settings → Knowledge Bases. This is the “memory” the chatbot relies on to answer.

    1. Create a knowledge base.
    2. Upload the documents (PDF, DOCX, TXT, or direct text).
    3. Wait for processing — the document goes through a status: processing, then ready.
    4. Check the analytics to see the questions that went unanswered.
    5. Add missing content or fix the rejected documents.
    💡

    The quality of the answers depends on the quality of the documents. Split the content into clear topics, and avoid scanned images with no text.

    3. Chatbot

    From Settings → Chatbot.

    1. Create a bot and choose the linked knowledge bases.
    2. Set the welcome message, the tone, and the language.
    3. Link it to a channel (WhatsApp/widget) according to the available settings.
    4. Test it in the preview before enabling it.
    5. Enable it. It can be paused at any time.

    The Free plan does not include chatbots (0). Starter = 2, Pro = 5, Business = 25.
