    Contacts & Segments

    Contacts are the heart of the system: campaigns, segments and leads are all built from them. This guide explains manual entry, smart importing, and building segments without duplicate records.

    Contacts list

    Go to Contacts ← Contacts. The list shows name, phone, email, tags and segments, with instant search.

    • Click any contact to open its full profile (messages, linked leads, activity).
    • Use search by name, phone or email.
    • You can export from the same screen or from Reports, depending on your permissions.

    Adding a contact manually

    1. Click Add contact.
    2. Enter the name and phone number in international format (example: 201012345678).
    3. Add email, company and tags if you wish.
    4. Save.
    ⚠️

    The phone number is the primary key for the channel. Always enter it in international format without the + or leading zeros, otherwise sending on WhatsApp and SMS will fail.

    Importing contacts

    There are two paths: quick import (CSV) and the table import (Bulk Import), which works like an Excel sheet inside the browser.

    Quick import (CSV)

    1. From the contacts list, click Import.
    2. Upload a CSV file encoded in UTF-8.
    3. Match the columns: phone is required, the rest are optional.
    4. Review the number of valid and rejected rows before confirming.
    5. Click Import.

    Table import (Bulk Import)

    1. Open Advanced import.
    2. Paste the data or upload a CSV/XLSX file.
    3. Map the columns: name, phone, email, company, tags, segment.
    4. Rows missing a phone are flagged as errors and are not imported.
    5. Review the summary, then confirm.
    💡

    Before any large import: try 10 rows first, and make sure the number format is correct. A bad import is harder to clean up than manual entry.

    Duplicates during import

    The system prevents creating a duplicate contact with the same phone number within the same workspace. When a match is found, the existing record is usually updated instead of creating a new copy — check the import summary to see the number of "updated" and "added" records.

    Segments

    A segment is a dynamic group of contacts that updates automatically according to rules. Go to Contacts ← Segments.

    1. Click New segment.
    2. Choose the combiner: AND (all conditions) or OR (any condition).
    3. Add the conditions: field + operator + value. Example: phone_e164 "contains" 2010.
    4. You can use the "is empty" and "is not empty" operators without a value.
    5. Save — the segment appears with the number of matching contacts.

    Adding contacts to a segment manually

    Next to each segment there is an Add contacts button that opens a multi-select screen. Use it for static segments (such as "Showroom customers").

    Use caseSegment example
    Campaign for a cityCity = Cairo
    VIP customersTag contains "VIP"
    Incomplete dataEmail is empty
    Follow-up after purchaseTag "Purchased" + last activity within 30 days

    Tags

    Tags are manual and quick, and differ from segments in that they do not update automatically:

    • Add or remove a tag from the contact profile.
    • Add tags to several contacts at once from bulk actions.
    • Tags are used in campaign filters and automation triggers.

    Custom fields

    Go to Settings ← Custom fields (if included in your plan). Add fields such as "City", "Favourite product", "Date of birth".

    • Choose the type: text, number, date, select list...
    • The fields appear on the contact form and during import.
    • They can be used in segment conditions and automation.
    💡

    The number of custom fields is limited by plan (Free = 3, Starter = 10, Pro = 20, Business = unlimited).

    Contact fields reference

    Every contact record carries the same core fields. Custom fields are added on top from Contacts → Custom fields.

    FieldWhat it means
    NameDisplay name used in the inbox and campaigns. Required.
    PhoneThe WhatsApp/SMS number in international format. Usually the unique key for messaging.
    EmailUsed for email campaigns, quotes and invoices.
    CompanyLinks the contact to a company record.
    OwnerThe team member responsible for this contact.
    SourceWhere the contact came from: manual, import, WhatsApp, form, store or API.
    TagsFree labels for filtering and segmentation.
    Custom fieldsAny extra attribute you defined, shown on the contact profile.
    Created atWhen the record first entered the workspace. Used by reports and retention rules.

    Contact profile

    It opens everything related to the customer:

    • Basic data, tags and segments.
    • Previous conversations across all channels.
    • Linked leads and deals.
    • Activity log (messages, changes, tasks).

    Bulk actions

    Select several contacts from the list, then:

    • Add/remove tags.
    • Add to a segment.
    • Export the selection.
    • Delete (with care — this may affect reports).

    Common problems

    ProblemCauseFix
    Rejected rows during importMissing phone or wrong formatCorrect the numbers and import again

    Empty segmentA condition that matches no recordCheck the operator and value, and try OR instead of AND
    Custom field not showingNot included in the plan or disabledCheck your plan and the field settings
    "You have reached the contacts limit"Plan limit exceededExisting data still works, but new additions stop — upgrade your plan
